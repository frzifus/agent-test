# Issue #4: Add IsOdd and IsEven functions to math package

## Problem

The math package currently has basic arithmetic functions (Add, Sub, Mul, Div) but is missing parity checks. The task is to add two new functions:
- `IsOdd(n int) bool` — returns true if n is odd
- `IsEven(n int) bool` — returns true if n is even

These functions must handle negative numbers correctly. Tests should be added for both functions including edge cases (0, negative numbers, large numbers).

## Current State

The codebase contains a single file `math.go` in the `agent_test` package with the following functions:
- `Add(a, b int) int` — currently returns 0 (TODO)
- `Sub(a, b int) int` — currently returns 0 (TODO)
- `Mul(a, b int) int` — currently returns 0 (TODO)
- `Div(a, b int) (int, error)` — currently returns 0, nil (TODO)

No parity check functions exist. No test files exist in the repository.

## Proposed Changes

### Files to Modify

1. **math.go** — Add two new functions:
   - `IsOdd(n int) bool` — returns `n % 2 != 0`
   - `IsEven(n int) bool` — returns `n % 2 == 0`

### Files to Create

1. **math_test.go** — Add test file with:
   - `TestIsOdd` — test cases for IsOdd function
   - `TestIsEven` — test cases for IsEven function

### Function Signatures

```go
func IsOdd(n int) bool
func IsEven(n int) bool
```

### Implementation Notes

- Use modulo operator (%) to check parity
- Go's modulo operator handles negative numbers correctly for parity checks
- `n % 2 == 0` means even, `n % 2 != 0` (or `n % 2 == 1` or `n % 2 == -1`) means odd
- For negative numbers: -3 % 2 = -1 (odd), -2 % 2 = 0 (even)
